# 曲线 V2 模型升级验收（2026-08-21）

本报告对应 `schema_version=curve.v2`，实验运行标识为 `curve-v2-regression-20260821`。
曲线结果把观测层、趋势层和预测层分开计算，并保留旧字段 `actual / fitted / forecast` 以兼容旧页面。

| 项目 | 结果 |
|---|---|
| 指标策略 | 血压收缩压/舒张压分别建模；血糖按空腹/餐后/随机条件分组；体重与静息心率按稳健日聚合；步数、睡眠和综合健康分不做精确未来数值外推 |
| 预测门槛 | 少于 7 个有效日不判断；7～20 日只展示趋势；≥21 个有效日且跨度 ≥28 日最多预测 7 日；≥42/56 日最多 14 日；≥84/90 日仅给 30 日周级区间 |
| 模型选择 | 最近值、滚动中位数、稳健局部线性、Huber 阻尼、鲁棒局部水平候选；按滚动 1/3/7 日回测选中模型，线上使用同一模型 |
| 区间 | 基于滚动残差的 80% 区间，随预测距离扩大，满足 `lower ≤ predicted ≤ upper` 并受合理范围约束 |
| 新输出 | `raw`、`clean`、`smooth`、`baseline`、`series[]`、`forecast_interval`、`backtest`、`eligibility`、质量标记和拒绝原因 |
| 回归结果 | Python Curve V2 28/28 通过；血压双序列、真实时间戳、行为指标拒绝预测和条件分组接口已验证 |

血糖必须在同一测量条件下达到门槛；历史条件为 `unknown` 时不混合空腹/餐后建模，接口返回 `forecast.available=false` 并提示继续规范记录。预测表示模型估计，不是医学诊断；高波动、误差过大或区间过宽时主动停止预测。

## 关键验收断言

- 同一天多次测量保留原始记录 ID，异常点不再用聚合数组索引标记。
- 横坐标由真实时间戳计算，预测从趋势终点衔接，不从单次异常原始点跳变。
- 血压同时输出 `bp.systolic` 与 `bp.diastolic`；血糖条件互斥。
- 没有固定“45%可信度”；老人端显示数据充分度，模型详情显示 MAE/MASE/区间覆盖率。
- 旧字段仍由主序列派生，旧页面和智能体接口保持兼容。
