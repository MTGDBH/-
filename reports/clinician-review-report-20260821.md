# GraphRAG 医学审核报告（待签署版）

## 1. 报告定位

本报告是提交材料用的审核状态报告，不是医生签字证明，也不是临床有效性结论。审核对象来自 GraphRAG 索引 `2026-08-21.v6`，所有高风险关系在完成资质人员审核前仍保持 `pending_medical_review`。

## 2. 审核对象与证据

- 高风险关系：83 条；
- AI 预审核结果：66 条允许演示/健康教育，17 条必须临床确认，0 条直接拒绝；
- 证据来源：78 个来源、111 个分块、159 个实体、419 条关系；
- 关系覆盖：高血压、2 型糖尿病、心血管疾病、脑卒中、慢性肾脏病、老年衰弱/跌倒风险；
- 每条关系均保留来源、证据等级、适用人群、条件、因果状态和原始审核状态。

## 3. 已生效的安全门控

1. 老人端阻断 16 条高风险关系；
2. 医生/审计视图保留完整关系路径，但不改变批准状态；
3. 急症、用药、阈值、疾病因果和虚弱/跌倒关系不得由模型给出确定性医疗结论；
4. 来源门控默认对 4 类 legacy 待复核来源显式标记，严格模式可排除；
5. `apply_clinician_reviews.py` 只有在 83 条关系全部签署且无 `needs_revision/reject` 时才允许生成版本化批准文件。
