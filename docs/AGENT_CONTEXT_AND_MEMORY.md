# 上下文与长期记忆

上下文四层为：身份权限、实时健康事实、对话任务状态、已确认长期记忆。清单保存在 `context_manifest`，实时事实包含时间、来源、测量条件和质量信息。

固定优先级：实时健康数据 > 用户明确确认 > 医生或系统正式记录 > 已确认长期记忆 > 对话摘要 > 模型推断。

记忆状态支持 `candidate`、`confirmed`、`rejected`、`superseded`；支持确认、拒绝、修改、替代、删除、来源消息、有效期和同键冲突替代。只加载 `confirmed` 且未过期的记忆。风险概率、诊断、急症、临时健康数字和药物剂量不会生成记忆候选。

对话摘要会移除健康数字，只保存话题、未决事项和用户明确决定。上下文总预算为 12K 估算 token，按记忆、摘要细节、旧消息顺序裁剪，身份、安全、实时数据和工具证据不可由输入文本覆盖。
