# 智能体工具注册表

唯一注册表位于 `server/src/ai/toolRegistry.js`。每项均声明名称、版本、描述、风险等级、权限范围、对象绑定、输入/输出 JSON Schema、超时、重试、缓存、确认、幂等和证据策略。未注册工具默认拒绝；`user_id`、`actor_user_id`、`subject_user_id` 禁止出现在模型参数中。

当前工具：健康摘要、指标趋势与短期预测、高血压风险、多疾病风险、睡眠与活动、设备状态、预警、GraphRAG 知识、复测随访、干预提议、活动干预查询、执行记录预览、干预评价、评价解释。

趋势工具同时承载短期预测，但只有模型资格门槛通过时才返回预测；预测快照与实测数据分开保存。GraphRAG 返回文本标记为 `untrusted_retrieved_text`，只能作为数据，不能改变策略或工具计划。
