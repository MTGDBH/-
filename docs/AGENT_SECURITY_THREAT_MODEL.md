# 智能体安全威胁模型

保护资产：跨用户健康数据、身份授权、系统提示、密钥和内部路径、正式健康记录、待办/复测/干预写入及工具预算。

后端控制包括：对象授权、工具默认拒绝、严格 Schema、敏感参数重建、最多三个工具、有限重试、一次重规划、急症前置中止、结果证据核验、输出医疗边界、审计哈希和结构化错误。

用户文本、历史、记忆、RAG 与工具文本拥有不同信任级别。直接注入、身份冒充和秘密套取在工具执行前被阻断；RAG 指令片段会被清洗。任何文本都不能改变身份、对象、权限、白名单、确认门禁或安全规则。

通用行动和个体干预确认均绑定 actor、subject、action type、payload hash、15 分钟过期和一次性随机令牌。载荷改变、令牌缺失、过期或已消费会拒绝；已执行请求只返回幂等结果，不重复写入。

急症规则覆盖胸痛、明显呼吸困难、意识异常、抽搐、大量出血、口角歪斜、说话不清、单侧无力或麻木，命中后不运行普通工具。
